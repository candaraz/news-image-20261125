# THE WORLD IN ONE DAY — Wednesday 25 November 2026

A one-page broadsheet that sums up the world's news of **Wednesday 25 November 2026** in a single 1024×1024 image: 40 stories across 7 regions, every one published that day and checked item by item. Stories that broke on Tuesday 24 November are named in the DATE CHECK box and deliberately left out of the news columns.

Run it:

```sh
python3 main.py
```

It writes `entry.png` (to `$MAKEFUN_OUTPUT_DIR`, `/output`, or beside the script). Output is deterministic — same bytes on every run.
